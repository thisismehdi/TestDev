# TestDev

Une application web développée avec **React** et **Vite**, qui permet d'explorer les personnages de l'univers Rick & Morty grâce à l'[API officielle](https://rickandmortyapi.com/).

## 🚀 Fonctionnalités

- Rechercher un personnage par nom
- Filtrer par **genre**, **espèce** et **statut**
- Pagination avec navigation entre pages
- Ajouter/Supprimer des personnages en favoris (stockés dans `localStorage`)
- **Responsive** : s’adapte aux téléphones, tablettes et PC
- Navigation entre pages grâce à `react-router-dom`
  
## ⚙️ Technologies utilisées

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Axios](https://axios-http.com/)
- [React Icons](https://react-icons.github.io/react-icons/)
- [React Router](https://reactrouter.com/)
